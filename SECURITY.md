# Security policy

## Supported versions

Only the default branch is currently supported.

## Reporting a vulnerability

Please do not open a public issue for a credential leak, authentication flaw, order-routing
bug, or another security-sensitive problem. Contact the repository owner privately through
GitHub so the issue can be investigated before disclosure.

Never include KIS app keys, app secrets, account numbers, access tokens, request logs, or
brokerage statements in an issue or pull request.

This adapter is intended for KIS paper trading first. Independently verify order behavior,
market rules, and account permissions before considering any live use.
